## 1. Statement

normal closure of the 30 elements in tw:GB-presentation: 21 quadratic
rho_i, 2 cubic omega_j, 7 quartic theta_k). Write L_n = gr_n(F),
R_n = image(NB cap D_n) (tw:relation-space), I the restricted ideal of
gr(F) generated by the 30 generator initials, g_n = dim L_n/R_n,
S_n = Sum_{i<n} g_i.

Theorem (proved). dim R4 <= dim I4 + 28. With dim L4 = 1044,
dim I4 = 963 (41-cap), dim R4 in [963,991], g4 in [53,81],
S5 = 49 + g4 in [102,130].

Corollary (V-existence, proved). Since g4 >= 53 > 0, hyperplanes V with

central) and Q = GB/V has order 2^50 with |cl_Q(iota1)| >= 2^15
(C93 Sec 1b central case). Strict >= 2^16 still needs a lifting defect
(C93 Sec 4a), hence exact R4.

## 3. Repaired exhaustion proof (dim R4/I4 <= 28)

Work in Fbar = F/D5 (finite 2-group; D5 open). Then D4/D5 = L4 is central
([D4,D1] subset D5), exponent 2 (D4^2 subset D8), an F2-space; D3 is
abelian ([D3,D3] subset D6 = 1); [D3,D2] = 1; [D2,D2] subset D4.
Let Nbar be the image of NB (normal closure of the 30 images). Then
R4 = Nbar cap D4 as a subspace of L4, spanned by gr4-classes of finite
products of conjugates s^f (s among the 30, f in Fbar); inverses differ
by I4 (for s in D2, s^{-1} = s.(s^2)^{-1} with (s^2)^{-1} in (R2)^[2];
for s in D3/D4, s^2 = 1 so s^{-1} = s).

Fix lifts X_l of the gr1 basis (free generators). Write each occurrence
(rho_i^e)^f with e mod 4 as e = e0 + 2e1 (e0,e1 in F2):
rho^e = rho^{e0}.(rho^2)^{e1}, the second factor in D4 with class in
(R2)^[2] subset I4 (central, conjugation-trivial); if e0 = 1,
(rho)^f = rho.[rho,f]. Similarly (omega^e)^f = omega^{e0}[omega^{e0},f]
(omega^2 = 1) and theta^e is central in I4 by definition.

Collect w in Nbar cap D4 as w = A.B.C with A = product of unconjugated
s-powers, B = product of [s,f]-commutators, C = reordering commutators.
Since [D2,D3] = 1 and [D3,D3] = 1, rho commutes with [rho,f] and D3
factors commute; reordering rho_i past rho_j gives [rho_i,rho_j] in D4
with class [r_i,r_j] in [R2,R2] subset [R2,L2] subset I4 (folding). So
C subset I4. Theta and rho-even powers contribute only I4. Hence mod I4,
w = (Prod_j omega_j^{D_j}).(Prod_{i,k}[rho_i,f_k]) with D_j in F2 and
the second product over odd rho-occurrences.

Gr2: B,C and omega/theta lie in D3/D4, so gr2(w) = Sum_i R_i r_i with
R_i = (Sum_k e0_{ik}) mod 2. Since w in D4, gr2 = 0; by R2 independence
(21), all R_i = 0: each rho occurs an even number of times mod 2, and
Prod_k rho^{e0_k} = (rho^2)^{Q_i} subset I4. The (rho_i)_3 subleading
parts cancel in gr3 (even multiplicity).

Gr3: w mod D4 = (Prod_j omega_j^{D_j}).(Prod[rho_i,f_k]) has class
Sum_j D_j c_j + Sum_i [r_i,F_i] in L3 with F_i = Sum_k f_{k,1} in L1.
Since w in D4, this is 0 in L3. Expanding F_i = Sum_l a_{il} x_l gives a
syzygy vector (a,D) in F2^{170} in the 28-dim kernel (170 -> 142).

Gr4 mod I4: D3 abelian gives additivity (degree-3 cross terms land in
degree >= 6). So gr4(w) = Sum_j D_j t_j + Sum_{i,k} gr4([rho_i,f_k]) mod
I4, with fixed unknowns t_j = (omega_j)_4. For each [rho_i,f], write
f = x.u with x = Prod_l X_l^{a_l} (same gr1) and u in D2. Then
[rho,f] = [rho,u].[rho,x] ([[rho,x],u] = 1 since [D3,D2] = 1).
[rho,u] has class [r_i,u_2] in [R2,L2] subset I4 (folding). By
[a,bc] = [a,c][a,b][[a,b],c] induction, [rho,x] = (Prod_l[rho,X_l]^{a_l})
.(I4), the double brackets [[rho,X],Y] having classes in
[[R2,L1],L1] subset I4. Hence [rho_i,f] mod I4 = Sum_l a_l s_{il} with
fixed vectors s_{il} = gr4([rho_i,X_l]). Summing gives
gr4(w) mod I4 = Sum_{i,l} a_{il} s_{il} + Sum_j D_j t_j = psi(a,D)
for a fixed linear psi: F2^{170} -> L4/I4. Since (a,D) lies in the
28-dim kernel, R4/I4 subset psi(kernel), dim <= 28. The 28 vectors
psi(k_1)..psi(k_28) for any kernel basis lie in R4 (syzygy lifts
Prod[rho,X]^a.Prod omega^D are in NB cap D4 with gr3 = 0), so
R4 = I4 + span{28 corrs}, dim R4 <= 963 + 28 = 991. With I4 subset R4,
dim R4 in [963,991], g4 = 1044 - dim R4 in [53,81]. QED.

Fiber-dependence: s_{il},t_j depend on the true lifts (positions T'),
but the COUNT (dim image <= 28) does not. Exact R4 = I4 + span(28
corrs(T')) still needs T'; the 248-dim bookkeeping budget (C93 Sec 4d)
is unchanged.
