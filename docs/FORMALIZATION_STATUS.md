# Formalization status

The Lean formalization of the main result proves the planar sequence
statement at exponent `10427/10000 = 1.0427`, conditional on one explicit
numerical inequality for the Dedekind zeta function of a fixed degree-512
number field over `ℚ(√241)`. The inequality is not proved in Lean. The
source package is being added to this repository under `lean/`, together
with its verification status. No Palomar submission has been made.
