(Frob 29₁, Frob 29₂, F₇²). Place index `P : Fin 2`: 0 = 𝔭₁ (distinguished;
its genuine relation is a consequence), 1 = 𝔭₂ (literal `y₂²`).

`comm a b = a⁻¹b⁻¹ab` (`Dyadic.Presentation.comm`),

    (hσ : A.SigmaStable H f σ) (hcover : ∀ g : Ĝ, g ∈ H ∨ σ⁻¹*g ∈ H) :
    (A.kernel.map f.toMonoidHom).Normal

-- T7: retention of Q_B and a class of size ≥ 2^15 (free source)

  `tameInertia tameFrobenius : Fin 4 → Source` (𝔮₁, 𝔮₂, 𝔯₁, 𝔯₂),
  `dyadic : Fin 2 → (LocalSource →ₜ* Source)` (𝔭₁, 𝔭₂; `LocalSource =

  `Presentation.LocalElements.sourceLifts`; T5 gives `Local.localElements`.

  (T6: `LocalElements.sourceLifts_labels`). Alternatively
  `Cut.SourceLifts.labels_of_elementary` with any continuous elementary map.
* **Genuine relation.** `r := Presentation.genuineRelation`,
  `hr := Presentation.detector_genuineRelation` (T6).
* **Presentation.** `A.Presentation r : A.dyadic 0 r ∈ closedNormalClosure
  (Set.range (A.relators r))` (T6: `LocalElements.presentation`; T5:
  `localElements_presentation`).
* **Ĝ level (T9).** Done concretely in `Cut/SigmaB`: `Cut.B.freeToGhat =
  GB.subtype ∘ freeMap`, `Cut.B.kernelHat = A.kernel.map freeToGhat` with
  `kernelHat_le_GB`, `kernelHat_isClosed`, `comap_kernelHat`, `kernelHat_normal`
  (σ̂-stability `B.sigmaStable` from T5's `tame_sigma`, `dyadicLocal_sigma`,
  `frob29_sigma`, `coe_conj₂`, `frob7_not_mem`; conjugators `h σ̂`, `h ∈ G_B`)
  and `ghat_quotient_infinite`. Generic forms (any `Ĝ`, `H`, `f`, `σ`) in
  `Cut/Descent`.
* **Retained map (T9).** `retainedFree` kills `A.kernel`
  (`Retained.closedNormalClosure_le_ker`) and the relators
  (`relators_closure_le_retained_ker`), is surjective (`retainedFree_surjective`),
  equals `reduction ∘ Universal.freeDetector` (`retainedFree_eq_reduction`).
