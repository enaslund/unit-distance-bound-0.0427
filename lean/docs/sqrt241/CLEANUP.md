# Cleanup pass of the ℚ(√241) development (2026-09-29)

Submission-quality cleanup after an independent code audit (findings S1–S8 and
cosmetic items). Scope: comments and docstrings, option scoping, proof-internal
replacements of deprecated lemmas and style suggestions, headers, generators and
documentation. **No theorem statement, no definition's value, and neither
`ChallengeZeta241.lean` nor `SolutionZeta241.lean` was changed.** A comparison of every
Lean file of `UnitDistance/Sqrt241/` with its pre-cleanup copy that ignores comments and
docstrings finds code differences in exactly the 35 files named under S7 and S8

  `if_pos`/`if_neg`/`dif_pos`/`dif_neg` → `ite_eq_left`/`ite_eq_right`/`dite_eq_left`/

  `Geometry/{FixedBaseBridge, ImaginaryRootUnramified, QuadraticRootNormCongruence}`,
